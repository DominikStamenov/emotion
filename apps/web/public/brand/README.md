# eMotion brand assets

Generated from the supplied official eMotion PNG mark.

## Files

- `emotion-mark.svg` — primary scalable vector mark with transparent background
- `emotion-mark-transparent.png` — 2048×2048 transparent raster mark
- `emotion-mark-transparent-1024.png` — 1024×1024 transparent raster mark
- `emotion-mark-mask.png` — white alpha mask for the Hero particle solver
- `emotion-mark-white.svg` — monochrome white mark
- `emotion-mark-black.svg` — monochrome dark mark
- `favicon.svg` — favicon tile
- `favicon-32x32.png` — browser fallback
- `favicon-192x192.png` — PWA/browser fallback
- `apple-touch-icon.png` — 180×180 Apple touch icon

## Recommended project location

Copy all files into:

`apps/web/public/brand/`

The primary website source should be:

`/brand/emotion-mark.svg`

The Hero particle mask should be:

`/brand/emotion-mark-mask.png`
